# M.A.R.I. (Mnesis, Aletheia, Reverie, Infernia)

This project aims to build M.A.R.I., an adaptive, self-sustaining intelligence designed to interact with the subconscious via a dynamically evolving virtual realm called the Dreamscape.

**Current Status (Phase 1 - Reverie):** Core architecture implemented, including text analysis (sentiment, NER, topics via Zero-Shot), state management, and a concept mapper using a fine-tuned T5 model incorporating state feedback. Dataset expanded, model re-trained. Placeholders for advanced NLP (coref, relations) and explicit feedback added. Testing guide (`TESTING.md`) created.

## Components

M.A.R.I. is envisioned as a collective of four specialized AIs:

1.  **Mnesis:** (Memory/History - TBD)

3.  **Reverie:** (World Generation/Dream Formation/Subconscious Interaction - **Initial Focus - In Progress**)

## Reverie: The Dream Weaver

Reverie is the first AI component under development. Its primary role is to generate and manage the Dreamscape, a living, self-evolving world that responds to user input (currently text) and its own internal state.

Reverie's neural network will form the foundation of the M.A.R.I. system. Key definitions are in `REVERIE_DEFINITION.md`.

### Reverie Architecture

1.  **Input Processor (`src/reverie/input_processor.py`):** Tokenizes raw text input using Hugging Face tokenizers.
2.  **Text Analyzer (`src/reverie/text_analyzer.py`):** Analyzes text for sentiment, named entities (NER), topics (zero-shot), and generates embeddings. Includes placeholder integration with `spaCy` for future coreference resolution and relation extraction.
3.  **Concept Mapper (`src/reverie/concept_mapper.py`):** A fine-tuned T5 model that translates analyzed text and current dream state into actionable commands. Uses state feedback (theme, last action) to generate more contextually relevant commands.
4.  **Dreamscape Manager (`src/reverie/dreamscape_manager.py`):** Manages the state of the "dream," applying commands generated by the Concept Mapper. Includes a placeholder for recording user feedback on generated commands.
